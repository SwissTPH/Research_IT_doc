# Using Swiss TPH Skills in ChatGPT and Claude

This document explains how to use **Swiss TPH-provided skills** in ChatGPT and Claude **for users with a Swiss TPH AI subscription**.

**Please follow the instructions below for the application you are using.**



## 🌐 ChatGPT Web

**No installation required.** Swiss TPH-provided skills are **already available** in your ChatGPT web account.

1. Open [ChatGPT](https://chatgpt.com/).
2. Type **@** in the chat and select the skill you want to use.



## 💻 ChatGPT Desktop App (Windows)

**Manual installation from the web is required.**

1. Open [ChatGPT](https://chatgpt.com/).

2. In the sidebar, go to **Plugins → Skills**.

3. Find the Swiss TPH skill you want to use, click the **three-dot (···)** and select **Download**.

4. On your laptop, open your **Downloads** folder, locate the downloaded ZIP file, right-click it and select **Extract All**.

5. Move the **extracted skill folder** (not the ZIP file) into the following directory:
   `C:\Users\<your_username>\.codex\skills\`

   Replace `<your_username>` with your Windows Swiss TPH username.

6. Restart the ChatGPT app if necessary.

7. To use the skill, type **@** followed by the skill name in your chat.



## 🌐 Claude Web

**Skills may need to be added to your account first.**

1. Open [Claude](https://claude.ai/) and in the sidebar, go to **Customize → Skills → Yours**.
2. Add the Swiss TPH-provided skills using **three-dot (···)**.
3. Use skills by typing **/** followed by the skill name in your chat.



## 💻 Claude Desktop App (Windows)

**Skills need to be added to your account first.**

1. Open Claude and go to **Customize → Skills → Yours**.
2. Add the Swiss TPH-provided skills using **three-dot (···)**.
3. Use skills by typing **/** followed by the skill name in your chat.
