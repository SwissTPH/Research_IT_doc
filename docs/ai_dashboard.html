How to read: The Artificial Analysis Intelligence Index (0–100) is a single blended quality score. The next four columns break it down: SciCode = writing working scientific analysis code (0–100%) – Artificial Analysis currently lists SciCode as under review after an independent audit flagged possible errors in its dataset, so read it with caution; Humanity's Last Exam = 2,158 frontier academic questions (0–100%); AA-Omniscience accuracy = share of 3,000 factual questions across 42 topics answered correctly (AA-Omniscience v1.1, 0–100%) – it counts correct answers only and says nothing about whether a model admits ignorance or invents an answer; GDPval-AA v2.1 = 220 real-world professional tasks across 44 occupations and 9 industries, scored as an Elo rating from blind pairwise comparisons and shown as Elo, the way Artificial Analysis now publishes it – a relative ranking against other models, not the share of tasks completed correctly. Open = weights publicly downloadable. Vision/Video = input modalities beyond text. Open-weights status comes from the Artificial Analysis dataset; modalities were checked per model on Artificial Analysis or the provider's API docs. A missing badge means 'not confirmed', not 'not supported'. Only Muse Wonder Full (Meta) has confirmed audio input. Price = CHF per 1M tokens at USD 1 = CHF 0.8288 (28 October 2026). The leaderboard page now shows cost per task rather than a per-token price, so we calculated the blended rate ourselves from the Artificial Analysis list prices using its published 7:2:1 ratio of cache-hit : input : output tokens. It is a per-token rate, so it is identical for every reasoning-effort setting of a model – what changes is how many tokens the model spends. Speed ≈ words/sec. Context = max text at once. Suffixes such as (max), (high), (medium) are reasoning-effort settings of the same model, scored separately. 'not reported' means the value is not published; those cells always sort to the bottom.
